### 🛠️ About Me

I'm a **DevOps engineer** focused on AWS cloud infrastructure, networking architecture, and automating everything I can get my hands on. I build and tear down infrastructure daily — exploring different AWS service combinations, optimising architectures, and going deep on cloud networking.

- 🚀 Currently building CI/CD pipelines and production-grade deployment patterns on AWS
- ☁️ Hands-on with **ECS, ALB, Auto Scaling, VPC, Transit Gateway**, and more
- 🌍 Completed a **multi-region AWS project** with Transit Gateway peering across Ireland & London (5 VPCs, BGP routing, Ansible + Terraform)
- 📝 I write about what I learn at **[dtcloudnetworking.com](https://dtcloudnetworking.com)**
- 💬 Ask me about **Terraform** — I use it every day
